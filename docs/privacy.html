개인정보처리방침

시행일: 2026년 11월 26일

이 방침은 망상실험실 업로더(이하 "앱")가 Google 계정 정보를 어떻게 다루는지 설명합니다. 앱은 채널 운영자가 자신의 YouTube 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다.

1. 사용하는 정보

  • Google OAuth 로그인으로 받은 액세스 토큰과 리프레시 토큰
  • 로그인한 계정의 YouTube 채널 기본 정보(채널 ID, 채널 이름)
  • 업로드하는 영상 파일과 제목·설명·태그·공개 범위

2. 이용 목적

위 정보는 운영자 본인의 YouTube 채널에 영상을 업로드하고 업로드 결과를 확인하는 데에만 사용합니다. 광고, 분석, 프로필 작성 등 다른 목적에는 사용하지 않습니다.

3. 저장과 보관

토큰은 운영자의 개인 컴퓨터에 있는 로컬 설정 파일에만 저장되며, 별도 서버나 데이터베이스로 전송하지 않습니다. 운영자가 앱 사용을 중단하거나 접근 권한을 철회하면 토큰은 삭제됩니다.

4. 제3자 제공

수집한 정보는 판매하거나 제3자에게 제공하지 않습니다. 정보는 업로드를 위해 Google(YouTube)에만 전송됩니다.

5. YouTube API 서비스

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

6. 접근 권한 철회

Google 계정 보안 설정에서 언제든 앱의 접근 권한을 철회할 수 있습니다.
