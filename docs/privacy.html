개인정보처리방침

시행일: 2026년 11월 26일

이 방침은 망상실험실 업로더(이하 "앱")가 Google 계정 정보를 어떻게 다루는지 설명합니다. 앱은 채널 운영자가 자신의 YouTube 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다.

1. 사용하는 정보

  • Google OAuth 로그인으로 받은 액세스 토큰과 리프레시 토큰
  • 로그인한 계정의 YouTube 채널 기본 정보(채널 ID, 채널 이름)
  • 업로드하는 영상 파일과 제목·설명·태그·공개 범위
  • 운영자 본인이 올린 영상의 통계(조회수, 좋아요, 평균 시청 시간, 시청 지속률)

2. 이용 목적

위 정보는 운영자 본인의 YouTube 채널에 영상을 업로드하고, 업로드 결과와 본인 영상의 성과를 확인해 다음 영상을 개선하는 데에만 사용합니다. 다른 사용자나 다른 채널의 데이터는 조회하지 않으며, 광고, 프로필 작성 등 다른 목적에는 사용하지 않습니다.

3. 저장과 보관

토큰은 운영자의 개인 컴퓨터에 있는 로컬 설정 파일에만 저장되며, 별도 서버나 데이터베이스로 전송하지 않습니다. 운영자가 앱 사용을 중단하거나 접근 권한을 철회하면 토큰은 삭제됩니다. 영상 통계는 운영자 컴퓨터의 로컬 파일로만 보관하며, 최대 30일이 지나면 삭제하거나 YouTube API로 새로 받아 갱신합니다.

4. 제3자 제공

수집한 정보는 판매하거나 제3자에게 제공하지 않습니다. 정보는 업로드를 위해 Google(YouTube)에만 전송됩니다.

5. YouTube API 서비스

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

6. 접근 권한 철회

Google 계정 보안 설정에서 언제든 앱의 접근 권한을 철회할 수 있습니다.

7. 데이터 삭제

로컬 설정 파일과 통계 파일을 지우면 앱이 보관한 모든 정보가 즉시 삭제됩니다. 삭제를 요청하려면 아래 이메일로 연락해 주세요. 요청을 받은 날로부터 7일 안에 삭제합니다.
